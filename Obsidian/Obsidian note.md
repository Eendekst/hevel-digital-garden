# An Obsidian note is a markdown file on your computer.

A markdown file is a text file that ends with ".md" on your computer.

They are used to write text in [markdown language](https://developers.google.com/tech-writing/one/markdown).

You can also write [[YAML|YAML]] properties on top of your notes for context and instructions.

Markdown is the programmatic language of AI.
