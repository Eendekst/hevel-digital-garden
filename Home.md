### All you need is Obsidian
___
[Obsidian](https://obsidian.md/) is a note taking app that writes markdown notes directly in your computer's file system.

An organized and thoughtful vault (main folder) requires no extensive study/knowledge and is the gate to local data sovereignty, Agentic AI and augmented context.

This whole website is done with Obsidian. I simply write markdown notes on my computer or phone and publish them online.

You can also link notes in obsidian like [[this]] to connect structures, thoughts and ideas. We call it the [[digital brain|Second brain]].

### What is the bridge of Human - AI communication
___
**[[YAML]] (Yaml Ain't Markup Language)**
A programming language created in 2001 is the Human-AI communication bridge 

In an [[Obsidian note]], you may, at the beginning of every note insert a YAML property table. A YAML property table is a list of properties of the note you are writing. 

All you have to do is type "---" at the beginning of a note.

For example, this very note has this YAML table on top of it;

``` YAML 
---
title: index
publish: true
created: 2026-07-10
modified: 2026-07-11
author: Jason
description: Hevel's digital garden homepage
tags: []
aliases:
  - home
  - here
cssclasses: []
cover: ""
--- 
```
Augmented Intelligence is the simple task of filling these properties manually. You may use other classification properties (type, links, role, status, etc.). You are free to design your YAML properties as you want (make sure to create templates (IYKYK)).

By adding classification to your notes you create a cognitive layer that is as easy to understand to human as it is for any computer system. For AI enthusiasts, it also is the most token efficient way to inject context and instructions to prompts and documents.
